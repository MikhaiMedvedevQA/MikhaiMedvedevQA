## О себе

Я QA-инженер в IT-компании, специализация — ручное и авто-тестирование B2B-приложений (B2C реже) для страхового бизнеса. Пишу и выполняю тест-кейсы, провожу исследовательское тестирование UI и API.

В настоящее время улучшаю свои скиллы, прохожу курс по автоматизации тестирования на Python. 
Стек: **Selenium + pytest + Allure**. Playwright — следующий этап.

## Как я делаю проекты

Я использую **vibe-кодинг** с [Claude Code](https://claude.com/claude-code): формулирую задачу и направление, контролирую процесс и проверяю результат, а агент пишет код, проектирует архитектуру и ведёт технические решения. Так человек отвечает за «куда идём и зачем», а агент — за «как это написать». Это не «код за тебя», а парная работа: я разбираюсь в предметной области и качестве, агент — в коде и инфраструктуре.

## Текущий проект

**QA-Ассистент: анонимизированный генератор чек-листов**. 
Это [конвейер](https://github.com/MikhaiMedvedevQA/QA_Vibe-coding), который обезличивает конфиденциальные данные в спецификациях и описаниях продуктов ПО для страхового бизнеса и генерирует по ним чек-листы и тест-кейсы для ручного тестирования.

- Python-анонимизатор: извлечение текста из `.xlsx`/`.docx`/`.pdf`/`.txt`, замена ПД и сущностей на структурированные псевдонимы (`PERSON_0001`, `BANK_0001`, `INS_0001`), устойчивый маппинг между прогонами.
- Скиллы Claude Code для генерации чек-листов: обязательность полей, значения по умолчанию, условная доступность, валидация, полное покрытие.
- Архитектура: стабильный слой данных (Excel → JSON) + меняющийся слой генерации (JSON → скиллы → чек-листы).
